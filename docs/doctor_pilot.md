# 肤智（DermAgent）医生试点评审材料

> 版本：v41 · 日期：2026-09-11 · 适用：医生端桌面应用（PySide6）+ 可信服务层（FastAPI）

## 一、AI 辅助建议与医生决策边界（必读）

肤智提供的是**医生辅助判断**，不是自动诊断。所有输出均为「AI 辅助建议，仅供具备资质的医生参考，不能替代医生的独立判断」。

系统**不会**：

- 自动作出最终诊断或排除严重疾病；
- 把可能性排序称为确诊概率（界面一律标注「辅助排序——非确诊概率」）；
- 自动开处方、停药改药、调整剂量；
- 自动决定急诊、住院或手术；
- 自动执行治疗；
- 未经医生确认写入正式病历、提交医嘱或电子处方。

医生**整份审核** AI 建议后，系统最多生成**待签署草稿**；最终签署与执行由医生在授权目标医疗系统中完成。

## 二、试点数据要求

- 本试点**只使用合成病例或脱敏数据**；
- 医生端默认脱敏：姓名、身份证号、电话、地址在发送前自动替换为类别标记（可在辅助面板「发送预览」逐项核对）；
- 参考病例必须由医生**逐个确认**后才会参与分析（默认不读取其他病例）；
- 影像文件仅做本地格式/大小校验与展示，**不自动送模型分析**。

## 三、试点操作流程

1. **标注**：3D 人体模型上点选皮损部位（单点/多选/区域绘制均可），或直接在输入框描述；
2. **资料录入**：「＋」菜单 →「🩺 医生资料」录入病史/检验/报告/用药史，可添加影像；
3. **逐项选择**：「＋」菜单 →「🧠 医生辅助判断」确认本次随病例发送的资料项与参考病例；
4. **提交**：底部输入框发送（或直接发送 3D 选点）；服务端生成**待审核草稿**；
5. **审核**：在症状区查看鉴别方向（待排）、证据与引用、缺失资料、红旗、用药核对；
   - ✔ 确认生成辅助报告（待签署草稿）
   - ✎ 修订（输入修改意见后确认）
   - ⟳ 重新生成（服务端重新分析）
   - ✖ 拒绝（不生成报告，病例关闭）
6. **导出**：报告导出为 Markdown；草稿可导出 JSON 供核对。

## 四、安全与降级行为（试点须知）

- 服务不可达时：客户端提示并保留本地资料，可切回离线演示模式（本地规则分析，无网络）；
- 模型输出非法时：服务端自动降级为规则稿，并在草稿「生成方式/不确定性」中标注；
- 每次审核（接受/修改/拒绝/重新生成）都进入**审核历史**，可在辅助面板「审核与审计」区查看；
- 所有敏感操作（提交/审核/导出/区域导出）均有审计记录。

## 五、验收状态摘要（v41）

| 项目 | 状态 |
|------|------|
| 原有 3D 标注回归 | verify_3d 探针全绿（含逐面语义/区域/校准/异常路径） |
| 医生辅助链路 | server pytest 22 例全绿（含 E2E、失败不变性、审计链） |
| 客户端回归 | client pytest 11 例 + vitest 412 例全绿 |
| 客户端密钥检查 | 无模型供应商 API key（凭证仅存在于服务端环境） |
| 隐私 | 默认脱敏 + 资料白名单 + 参考病例确认门禁 |
| 试点数据 | 仅合成/脱敏数据；真实患者数据不在本试点范围 |
