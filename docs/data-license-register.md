## 使用规则（与计划 §7.1/§7.2 对齐）

1. 仅上述已登记资料可进入演示知识库；「网上可见 ≠ 可复制/可再发布/可提交第三方 API」。
2. 知识库快照标识：`synthetic-kb@2026-09-03`（与输出 JSON 的 `knowledgeSnapshot` 一致）；资料变更必须升版本并更新快照。
3. 禁止抓取搜索引擎结果、付费书籍全文、含患者姓名/联系方式/病案号的页面。
4. 真实部署替换为平台侧已登记的授权 Knowledge 能力时，在本表追加对应条目并记录平台 targetId。
